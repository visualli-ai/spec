 💻 Run locally

The fastest way to experience Visualli is to run the demo on your own machine.

## Viewing Locally

Clone the repo, start a static server, and open the example previewer:

```bash
git clone https://github.com/visualli-ai/spec.git
cd spec
python3 -m http.server 8000
```

Then open [http://localhost:8000/examples/example.html](http://localhost:8000/examples/example.html) in your browser.

Modify [`example.visualli`](https://github.com/visualli-ai/spec/blob/main/examples/example.visualli) to your liking and refresh to see the changes live.
