# Visualli SDK

The official SDK for rendering `.visualli` documents:

| Package | Docs | Purpose |
|---|---|---|
| `@visualli-sdk/react` | [⚛️ React](react/getting-started.md) | 🎨 Ready-to-use React component — `<VisualliRenderer />` |

!!! tip "Getting started"
    Install `@visualli-sdk/react` — it automatically brings along `@visualli-sdk/core` (the parsing engine), React, and the other major dependencies.
