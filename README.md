## What is Visualli?

**Visualli** is an open standard for building comprehensible visualizations focused towards visual learners. Unlike traditional mind-maps or infographics built over rigid formats like XML or images, Visualli is designed from the ground-up to be streamable, hierarchical, and deeply extensible.

## Why Visualli?

- 🧶 **Layered** — Independent layers and levels enabling **detail on demand** for the end user.
- 🌳 **Hierarchical, yet flatter** — Deeply nested structures stay serializable as a **simple, editable** list of lines (JSONL).
- 🏗️ **Streamable** — Parse and render content **line by line** as it arrives. No waiting for the full download.
- 🧩 **Extensible** — First-class support for **semantic metadata**, visual themes, and custom payloads via the extension mechanism.
