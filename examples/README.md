# Visualli Examples

This directory contains example files demonstrating the Visualli specification.

## Files

*   **[example.visualli](./example.visualli)**: A comprehensive example showing the "Water Cycle". It demonstrates:
    *   Metadata header.
    *   Extensions (Semantic Anchors).
    *   Multiple hierarchical layers.
    *   Connections and Labels.
    *   Containers (Groups).

*   **[example.html](./example.html)**: A simple HTML previewer (work in progress) to visualize the data.
