# Parsers

This directory is reserved for specifications and reference implementations of Visualli parsers.

## Roadmap

- [ ] **TypeScript / Node.js Parser**: A reference implementation for the JS ecosystem.
- [ ] **Python Parser**: For data science and AI integrations.
- [ ] **Rust Parser**: High-performance parsing for native tools.

## Contributing

We welcome contributions of parsers in other languages. Please check [CONTRIBUTING.md](../CONTRIBUTING.md) for guidelines.
